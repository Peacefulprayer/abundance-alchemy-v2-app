## iPhone Core Audio follow-up

Music now uses a Web Audio gain stage for same-origin included tracks and authenticated uploads, avoiding iPhone media-element volume restrictions. Slider changes, fades, mute and narration ducking use that gain without restarting the track. Timer bells remain separate. Non-CORS external recordings retain native playback; iPhone system volume remains the fallback for those external sources.
